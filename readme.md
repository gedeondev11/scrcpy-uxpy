requirements:
- flask server
- python
os compatible:
1.  windows
2.  Apple 
3.  linux

install:

1.  instalar flask en tu sistema operativo
2.  descargar la ultima versión de scrcpy
3.  mover el archivo a la carpeta raiz de scrcpy
4.  ejecutar app.py con el comando 'python3 app.py'
5.  La interfaz se abrira en tu navegador web preferido y jugar con las opciones disponibles.
